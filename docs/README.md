# 🗂️ Documentación del Proyecto – SICAP

El directorio **`docs/`** reúne toda la documentación oficial del proyecto **SICAP**.  
Incluye los registros de desarrollo, documentación técnica y material de presentación utilizados en las distintas etapas del proyecto.

---

## 🧠 Propósito

Esta carpeta documenta el proceso completo del proyecto desde su planificación hasta la implementación final.  
Permite dejar constancia de:
- Las tareas realizadas por cada integrante.  
- Las pruebas de hardware y software.  
- Los resultados obtenidos y mejoras aplicadas.  
- El material usado en presentaciones institucionales o competencias.

---

## 🧾 Descripción de subcarpetas

### 📘 carpeta_de_campo
Contiene los registros cronológicos del trabajo diario del grupo.  
Cada documento detalla las actividades realizadas, los errores encontrados y las soluciones aplicadas durante el desarrollo.

### 🧩 carpeta_tecnica
Incluye todos los archivos técnicos que describen la estructura y funcionamiento del sistema:
- Diagramas eléctricos y de bloques.  
- Análisis del firmware y la arquitectura del servidor.  
- Documentación de componentes y conexiones.  
- Informes técnicos de validación y resultados.

### 🖥️ presentaciones
Reúne los archivos utilizados en exposiciones (ONIET, Feria de Ciencias, presentaciones institucionales).  
Incluye diapositivas, banners, afiches y material visual explicativo.
