# 🧾 Documentación del Proyecto SICAP

Este directorio contiene toda la documentación técnica, académica y visual del proyecto **SICAP (Sistema Inteligente del Control Automatizado del Pañol)**.  
Aquí se registran los avances mensuales, pruebas, presentaciones y material de referencia utilizado durante el desarrollo.

---

## 🧭 Propósito

El objetivo de este directorio es **centralizar toda la documentación producida durante el desarrollo del sistema**, garantizando trazabilidad y fácil acceso a:
- Bitácoras de campo de cada mes.
- Evidencia fotográfica y videos de funcionamiento.
- Documentos técnicos oficiales (ONIET, feria, informes).
- Cronologías y presentaciones institucionales.

---

## 🗓️ Carpeta de Campo

Cada archivo `.md` dentro de `carpeta_de_campo/` corresponde a un **registro mensual de avances**.  
Los registros incluyen:
- Actividades desarrolladas por cada integrante.  
- Pruebas realizadas en hardware y software.  
- Mejoras implementadas.  
- Conclusiones parciales y próximos pasos.

---

## ⚙️ Carpeta Técnica

La carpeta técnica reúne los documentos formales requeridos para la **presentación del proyecto ante ONIET y la Feria de Ciencias**, incluyendo planos, especificaciones y análisis del sistema.

---

## 🖼️ Presentaciones

Contiene los materiales visuales que acompañan las exposiciones:  
portadas, cronologías y presentaciones PDF con formato institucional.
