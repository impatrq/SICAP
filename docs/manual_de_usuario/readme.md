**Sistema Integral de Control Automatizado del Pañol**  
**Versión:** 2025  
**Autores:** Lautaro Santolucito, Pablo Osores, Facundo Spagnoletta, Facundo Ledesma, Tiziano Patella  
**Curso:** 7mo 1ra Aviónica – E.E.S.T. N°7 “Taller Regional Quilmes”

---

## 📄 Descripción General

El **Manual de Usuario de SICAP** ofrece una guía completa para la **instalación, configuración y uso** del sistema desarrollado por el equipo.  
SICAP es una solución tecnológica que automatiza el control de herramientas mediante **tecnología RFID**, eliminando registros manuales y aumentando la trazabilidad dentro de talleres, pañoles o empresas.

El documento fue creado para asistir tanto a técnicos instaladores como a usuarios del sistema.

---

## 🧩 Contenidos del Manual

El manual incluye las siguientes secciones:

1. **Glosario:** Definiciones técnicas de todos los componentes (ESP32, RFID, Router, Antena, Raspberry Pi, etc.).  
2. **Introducción:** Explicación del propósito, objetivos y posibles aplicaciones del sistema.  
3. **Hardware del Sistema:** Lista detallada de todos los componentes con su función y conexión correspondiente.  
4. **Precauciones Generales:** Advertencias de seguridad para evitar daños en los equipos o lecturas incorrectas.  
5. **Instalación Física:** Paso a paso para el montaje del portal RFID, conexión del lector, antenas, ESP32 y servidor.  
6. **Configuración Inicial:** Guía para acceder al sistema desde el navegador y ajustar los parámetros de red.  
7. **Guía de Uso:** Registro y administración de herramientas, usuarios y operaciones automáticas de entrada/salida.  
8. **Mantenimiento:** Buenas prácticas, rutinas de revisión y respaldo de datos.  
9. **Solución de Problemas:** Tabla de fallas comunes con causas y soluciones.  
10. **Contacto y Soporte Técnico.**
