# 🖥️ Presentaciones – Proyecto SICAP

La carpeta **`presentaciones/`** reúne todo el material final de exposición del proyecto **SICAP**.  
Aquí se incluyen los archivos preparados para ser presentados ante jurados, docentes y evaluadores en instancias como **ONIET**, **Feria de Ciencias**, y otras exposiciones institucionales.

---

## 🎯 Propósito

Reunir las **versiones definitivas y presentables** de los documentos del proyecto, con carátulas, formato visual uniforme y contenido final validado.  
Estos archivos reflejan el resultado final del trabajo del grupo y condensan la información técnica, funcional y estética del sistema SICAP.

---

## 📁 Contenido

- **Carpetas finales en formato PDF**: versiones con carátulas, índice, logos institucionales y secciones ordenadas.  
- **Informes resumidos**: síntesis técnica del sistema adaptada para exposiciones.  
- **Material gráfico complementario**: imágenes del producto terminado, capturas del sistema funcionando y banners de presentación.  
- **Archivos multimedia**: enlaces o recursos visuales usados durante las demostraciones.

---

## 🧩 Uso de los archivos

Estos documentos se emplean como soporte visual y escrito durante las exposiciones.  
Incluyen:
- La **carpeta técnica final** (con diseño y portada institucional).  
- Material para proyectar o imprimir durante la defensa del proyecto.
