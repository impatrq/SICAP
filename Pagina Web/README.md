# 🌍 Página Web - Proyecto SICAP

Este directorio contiene la **página institucional del proyecto SICAP**, desarrollada en **HTML, CSS y JavaScript puro**.  
Su objetivo es presentar el sistema de forma visual, clara y profesional ante evaluadores, docentes y visitantes externos.

---

## 🧠 Descripción general

El sitio web tiene como finalidad mostrar:
- Qué es el sistema **SICAP** y cuál es su propósito.  
- Las tecnologías empleadas (RFID, ESP32, Django, Ionic).  
- El equipo desarrollador con sus perfiles y roles.  
- Sus integrantes y la manera de contactarlos

La página está optimizada para mostrarse correctamente tanto en computadoras como en celulares.

---

## 🎨 Características visuales

- Diseño limpio, con colores institucionales y estética técnica.  
- Animaciones y transiciones suaves en los menús.  
- Estructura **HTML5 semántica**.
