
# 💻 Web App - Proyecto SICAP

Este módulo corresponde a la **aplicación web principal del sistema SICAP**, desarrollada sobre **Ionic Framework** con integración hacia el backend **Django**.  
Su objetivo es ofrecer una interfaz moderna, adaptable y conectada directamente con la base de datos del servidor.

---

## 🧩 Funcionalidad

La aplicación permite:
- Visualizar los registros RFID capturados por el firmware.  
- Administrar usuarios, herramientas y categorías.  
- Realizar búsquedas, filtrados y verificaciones en tiempo real.  
- Acceder al panel **Django Admin** directamente desde la interfaz web.  
- Operar desde dispositivos móviles sin pérdida de funcionalidad.  

---

## 🧠 Tecnologías principales

| Tecnología | Uso |
|-------------|-----|
| **Ionic Framework** | Estructura y diseño responsivo de la interfaz |
| **Angular / TypeScript** | Lógica de componentes y servicios |
| **Django (Python)** | API y base de datos embebida |
| **SQLite** | Almacenamiento temporal para pruebas locales |
| **HTML5 / CSS3** | Estilos y plantillas visuales |

## La WebApp de SICAP representa el punto de unión entre la tecnología RFID y la administración inteligente de recursos en tiempo real. Esta bajo constante desarrollo.
