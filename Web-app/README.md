# 🌐 Frontend - Proyecto SICAP

El directorio **/frontend** contiene la interfaz web del sistema **SICAP**, desarrollada con el framework **Ionic**.  
Esta aplicación permite visualizar y administrar los datos enviados desde el firmware y procesados por el servidor backend.

---

## 🧭 Descripción general

La interfaz web está diseñada para ofrecer una experiencia adaptable tanto en computadoras como en dispositivos móviles.  
Su objetivo principal es brindar al usuario un **panel de control visual** donde se pueden:

- Consultar los registros de herramientas y materiales.  
- Ver el historial de lecturas RFID.  
- Administrar categorías, ubicaciones y usuarios del sistema.  
- Supervisar en tiempo real los datos que llegan desde el backend.
